# Spoku mednieks

## Spēles nosaukums
Spoku mednieks

## Spēles mērķis
Spēles mērķis ir ar pogu “Noķert spoku” pēc iespējas ātrāk un biežāk iegūt punktus. Katrs nospiediens pieskaita vienu punktu, bet spēlētājam jāizvairās no bīstamiem spokiem un jācenšas noturēties noteiktajā laikā.

## Mapju struktūra
- `index.html` — galvenā spēles lapa ar HTML, CSS un JavaScript.
- `atteli/` — attēlu faili, piemēram, mednieka varonis `varonis.png`.
- `skanas/` — skaņas efekta fails `klikskis.wav`.
- `21.html`, `22.html`, `23.html`, `24.html`, `25.html` — iepriekšējo nodarbību un uzdevumu darba faili.

## Kā atvērt spēli
1. Atver mapes `2tema` saturu.
2. Ar dubultklikšķi atver failu `index.html` pārlūkprogrammā.
3. Lai dzirdētu klikšķa skaņu, nospied audio atskaņotāja pogu “Play”.
4. Lai iegūtu punktu, nospied pogu “Noķert spoku”.

## CSS dizaina izvēles
- Izvēlējos gaišu rozā fona kombināciju, jo tā veido maigāku, pasaku stila atmosfēru un labi saskan ar spoku mednieka tēmu.
- Spēles laukumu noformēju ar punktētu bordo apmali un ieapaļiem stūriem, lai tas izskatās draudzīgāks un būtu vieglāk atšķirams no pārējās lapas.
- Pogai izmantoju tumši bordo fonu, baltu tekstu un noapaļotus stūrus, lai tā labi izceltos un būtu viegli atpazīstama.
- Virsrakstu izcēlu ar tumši bordo krāsu un centrētu tekstu, lai galvenais nosaukums viegli piesaistītu uzmanību.
